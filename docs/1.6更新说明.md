# Tutuma Float Phone 1.6 更新说明

本次更新主要完善手机内的通话与常用社交功能。

- **Chat 通话：** 优化单聊、群聊语音和视频通话按钮、结束后的挂断显示、台词显示及长按菜单，统一较窄的竖排操作菜单。单聊和群聊视频通话均可临时上传本地视频（不超过 20MB、15 秒）；上传视频支持循环播放、默认静音，左上角音量条只调整视频原声，不影响角色语音。优化夜间模式输入栏与上传按钮颜色。
- **电话：** 统一通话按钮、台词操作菜单及布局；电话不增加悬浮小窗。
- **返回手势：** Chat 通话优先缩小为小窗；Chat 钱包返回到原页面；Weverse Live 返回时显示退出或后台播放选择。
- **提示音：** 内置 Chat、LYSN、电话、短信的八个默认音效；支持已有的自定义音效和恢复默认。
- **相册：** 已识图的真实照片或具有生成提示词的 AI 照片可参与自动匹配；照片仍受关联角色、AI 可用及使用历史等限制。长生图提示词可以正常换行。
- **X 与提问箱：** X 的 AI 生图支持保存进相册及继续作为动态／回复配图；提问箱可设置角色日历关联。

本版继续保留现有音乐分享卡片样式，不增加封面自动查找。未加入 YouTube、额外浏览器、内置 Chat CSS 方案或其他未开放功能。

**说明：** 已通过 Android 网页资源构建校验。实际通话手势、视频播放、音效和系统授权行为仍需安装后的手机测试。
