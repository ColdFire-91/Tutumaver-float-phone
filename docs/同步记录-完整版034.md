# 分享版同步记录

基于完整版资源 034 的源码整理。本轮将此前 031、032 的指定功能和 034 的小说改动同步到分享版。

- 日历月份页在日期区左右滑动切换角色；应用内返回手势逐层返回。
- Chat 头像圆角、角色作息时区与通话开口偏好；应用通知与本地自动备份。
- WVS 合播参与时段记忆、台上多条输入后飞机召唤；直播中文代输入及发帖平台来源。
- 提问箱问题与回答卡片分享到 Chat。
- 小说：热门一本至五本精确选择；原创与指定人物两条生成路径；专区主角、配角及宽松关系；中文默认正文、按需翻译、帖子翻译；读者评论评分与改稿标识；取消书架重复新建入口和关闭弹窗时误存草稿。

分享版保留原有聊天小窗口；不包含完整版独有的 YouTube、浏览器和幕后应用。IPA 未更新。
